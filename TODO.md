# План переработки Telegram бота в Telegram Web App (Mini App)

## Выполненные задачи (Архив)
- [x] **Web App (Архитектура, Shell, Конфиги, Быстрый запуск, Метрики):** Настроен Telegram Web App (FastAPI + HTML/JS). Реализованы безопасный shell, UI-терминал, запуск и сохранение конфигураций, отображение графиков метрик.

## Текущие и будущие задачи

### Шаг 4: Визуализация результатов
- [ ] **Отображение артефактов:**
  - Реализовать вкладку просмотра результатов: сгенерированные изображения, сохраненные чекпоинты и другие артефакты.

### Шаг 5: Тестирование обученных моделей (Inference)
- [x] **Интерфейс чата/промптов:**
  - Создать UI-компонент (похожий на чат или поле ввода), где пользователь может отправлять текстовые запросы в модель.
- [x] **Интеграция генерации текста:**
  - Настроить бэкенд на загрузку выбранной модели (из доступных чекпоинтов) и выполнение inference для возврата ответа пользователю прямо в Web App.

### Шаг 6: Интеграция с HuggingFace (Экспорт моделей)
- [ ] **Экспорт моделей:**
  - Добавить функционал для загрузки обученных весов и конфигураций модели прямо на HuggingFace Hub из Web App.
  - Реализовать скачивание моделей из Hub для Fine-Tuning или Inference.

### Шаг 7: Поддержка многопользовательского доступа
- [ ] **Авторизация и Роли:**
  - Внедрить ролевую модель (admin, viewer) для защиты эндпоинтов и UI дашбордов.
  - Обеспечить безопасный доступ к логам обучения только для авторизованных пользователей.
